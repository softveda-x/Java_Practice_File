🔹Level 1 – Basics (Variables & Operators)
1, Declare two integers and print their sum, difference, product, and division.
2, Swap two numbers without using a third variable.
3, Find the square and cube of a number.
4, Convert temperature from Celsius to Fahrenheit.
5, Find the area of a circle (take radius as input).

🔹 Level 2 – Type Casting
1, Convert a double value into integer and print both values.
2, Convert an integer into double and multiply by 2.5.

🔹 Level 3 – If / Else
1, Check whether a number is even or odd.
2, Check whether a number is positive, negative, or zero.
3, Find the greatest of two numbers.
4, Find the greatest of three numbers.
5, Check whether a year is a leap year.
6, Check whether a number is divisible by both 3 and 5.

🔹 Level 4 – Switch Case
1, Create a simple calculator using switch (+, −, *, /).
2, Print the day name based on day number (1–7).
3, Check whether a character is vowel or consonant.

🔹 Level 5 – Loops
1, Print numbers from 1 to 10 using for loop.
2, Print numbers from 10 to 1 using while loop.
3, Print sum of first 10 natural numbers.
4, Print multiplication table of a given number.
5, Print all even numbers between 1 and 50.
6, Count digits in a number.
7, Reverse a number.
8, Check whether a number is palindrome.
9, Find factorial of a number.

🔹 Level 6 – Break & Continue
1, Print numbers from 1 to 20 but stop when number becomes 15.
2, Print numbers from 1 to 20 but skip multiples of 3.
